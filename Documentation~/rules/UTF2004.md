# UTF2004 — Only TestDelegate is supported as the actual value of the AllocatingGCMemory constraint

Detects an actual value passed to `Assert.That` or `Assume.That` together with the `AllocatingGCMemory` constraint that does not bind to the `TestDelegate` parameter: a lambda or method group that returns a value (`Assert.That(() => dict.Remove(key), Is.Not.AllocatingGCMemory())`), or a variable of a delegate type other than `TestDelegate` (`Action`, `Func<T>`). `AllocatingGCMemoryConstraint` throws `ArgumentException` at runtime for these when the constraint is negated or otherwise wrapped (`Is.Not`, `.After(...)`), which is how it is almost always used.

| Item     | Value     |
|----------|-----------|
| Category | Assertion |
| Enabled  | True      |
| Severity | Error     |
| CodeFix  | False     |

Message: "Only TestDelegate is supported as the actual value of the AllocatingGCMemory constraint, but the actual value is '{0}': the assertion fails at run time. Use a lambda with a block body that returns nothing, or a method group of a void method."

`{0}` is the type the actual value argument binds to: the inferred delegate type for a lambda or method group (e.g. `ActualValueDelegate<bool>`), or the declared type of the expression otherwise (e.g. `Func<bool>`).

The diagnostic is reported at the actual value argument.

Severity is Error because the test cannot pass in the idiomatic negated form: the constraint throws `ArgumentException("The actual value must be a TestDelegate but was System.Boolean")`, and the code under test has already run outside the allocation recorder by the time it throws. An `Action` or `Func<T>` expression throws in every form, because it reaches `ApplyTo(object)` directly.

## Motivation

`AllocatingGCMemoryConstraint` is almost always used negated, as `Is.Not.AllocatingGCMemory()`, following the example in the Unity Test Framework documentation. `Is.Not` wraps the constraint in NUnit's `NotConstraint`. `NotConstraint` does not override `ApplyTo<TActual>(ActualValueDelegate<TActual>)`, so the inherited `Constraint` implementation runs: it invokes the delegate, takes its *return value*, and forwards that value to `ApplyTo(object)`. `AllocatingGCMemoryConstraint.ApplyTo(object)` requires a `TestDelegate` and throws `ArgumentException` for anything else.

A value-returning lambda or method group reaches that path because C# overload resolution prefers `Assert.That<TActual>(ActualValueDelegate<TActual>, IResolveConstraint)` over `Assert.That(TestDelegate, IResolveConstraint)` when both apply. The common trap is an expression-bodied lambda that calls a non-void method for its side effect, such as `() => dict.Remove(key)`, `() => set.Add(item)` on a `HashSet<T>`, or a fluent call like `() => builder.Append(x)`; the author never intends the return value to be asserted. The delegate body runs once, unmeasured, and then the assertion throws with a message that names the return type (`System.Boolean`) rather than the delegate, which is hard to connect to the fix.

A variable of type `Action` or `Func<T>` fails the same way through a different overload: neither type converts to `TestDelegate` or `ActualValueDelegate<TActual>`, so the call binds to `Assert.That<TActual>(TActual, IResolveConstraint)` and the delegate object itself reaches `ApplyTo(object)`. A variable of type `TestDelegate` works.

`AllocatingGCMemoryConstraint` itself overrides `ApplyTo<TActual>(ActualValueDelegate<TActual>)`, so the un-negated `Assert.That(() => dict.Remove(key), Is.AllocatingGCMemory())` runs and measures correctly. The rule still reports it: the intent and the fix are identical in both forms, a block-bodied lambda works in both, and exempting the un-negated form would require modeling which wrapping constraints forward the delegate and which evaluate it.

Verified against `com.unity.test-framework` 1.1.33, 1.3.4, 1.4.6, 1.6.0, and 1.7.0. All of them override `ApplyTo<TActual>(ActualValueDelegate<TActual>)`. The runtime behavior in this page was confirmed on 1.6.0.

### Why NUnit.Analyzers cannot be used instead

NUnit.Analyzers 3.9.0 has no rule about the delegate shape accepted by a custom constraint. Its type-compatibility rules (NUnit2021 and NUnit2022) know only the constraints shipped with NUnit.

## Bad

```csharp
using System;
using System.Collections.Generic;
using NUnit.Framework;
using UnityEngine.TestTools.Constraints;
using Is = UnityEngine.TestTools.Constraints.Is;

public class MyTest
{
    private readonly Dictionary<int, int> _dict = new Dictionary<int, int> { { 1, 1 } };

    [Test]
    public void Throws()
    {
        Assert.That(() => _dict.Remove(1), Is.Not.AllocatingGCMemory());   // UTF2004; binds ActualValueDelegate<bool>, throws ArgumentException
        Assert.That(RemoveOne, Is.Not.AllocatingGCMemory());   // UTF2004; method group of a bool-returning method

        Action action = () => _dict.Remove(1);
        Assert.That(action, Is.Not.AllocatingGCMemory());   // UTF2004; Action is not a TestDelegate

        Assume.That(() => _dict.Remove(1), Is.Not.AllocatingGCMemory());   // UTF2004; Assume.That throws the same way

        var constraint = Is.Not.AllocatingGCMemory();
        Assert.That(() => _dict.Remove(1), constraint);   // UTF2004; a local is followed to its initializer
    }

    private bool RemoveOne() => _dict.Remove(1);
}
```

## Good

```csharp
using System.Collections.Generic;
using NUnit.Framework;
using UnityEngine.TestTools.Constraints;
using Is = UnityEngine.TestTools.Constraints.Is;

public class MyTest
{
    private readonly Dictionary<int, int> _dict = new Dictionary<int, int> { { 1, 1 } };

    [Test]
    public void DoesNotAllocate()
    {
        Assert.That(() => { _dict.Remove(1); }, Is.Not.AllocatingGCMemory());   // block body returns nothing, binds TestDelegate
        Assert.That(RemoveOne, Is.Not.AllocatingGCMemory());   // method group of a void method

        TestDelegate code = () => _dict.Remove(1);
        Assert.That(code, Is.Not.AllocatingGCMemory());
    }

    private void RemoveOne()
    {
        _dict.Remove(1);
    }
}
```

## Notes

- The constraint argument is recognized by walking its invocation and member-access chain: the call is a candidate when any invocation in the chain returns `UnityEngine.TestTools.Constraints.AllocatingGCMemoryConstraint` (`UnityEngine.TestTools.Constraints.Is.AllocatingGCMemory()`, or the `.AllocatingGCMemory()` extension method on `ConstraintExpression` as in `Is.Not.AllocatingGCMemory()`), or any object creation in the chain is `new AllocatingGCMemoryConstraint()`. Wrappers before or after it (`Is.Not`, `.After(...)`, `.And`, `.Or`) change the static type of the argument but not the detection. A constraint held in a local variable is followed to the variable's initializer; a reassignment after the initializer, and a constraint held in a field or parameter or returned from a method, are not detected.
- The actual value is reported when it does not bind to the `TestDelegate` parameter of `Assert.That`/`Assume.That`: a lambda, anonymous method, or method group that binds to `ActualValueDelegate<TActual>`, or an expression that binds to the generic `TActual` parameter. A lambda with a block body that returns nothing, a method group of a `void` method, and an expression of type `TestDelegate` bind to `TestDelegate` and are not reported.
- An argument is excluded from UTF2004 exactly when the async-delegate classifier shared by UTF2002 and UTF2003 flags it; UTF2003 reports those (or UTF2002, when the chain is rooted in `Throws`, as in `Throws.Nothing.And.Not.AllocatingGCMemory()`), so each call is reported by exactly one rule. A `Task` value passed directly as the actual (`Assert.That(GetAsync(), Is.Not.AllocatingGCMemory())`) is not an async delegate, binds the generic `TActual` parameter, and is reported by UTF2004.
- A subclass of `AllocatingGCMemoryConstraint` is not detected; the chain check compares the exact type.
- The constraint argument is the one bound to the `IResolveConstraint` parameter, and the actual value is the argument bound to the first parameter whatever its type, so the message overloads `Assert.That(del, expr, message, args)` and `Assume.That(del, expr, message, args)` are matched the same way as the two-argument form.

To change the severity, add the following to `.editorconfig` or `.globalconfig`:

```editorconfig
dotnet_diagnostic.UTF2004.severity = warning
```
